# Bimmer 使用文档

Bimmer 是一个 macOS 菜单栏 App，对接宝马中国区互联驾驶（`myprofile.bmw.com.cn`），
在 Mac 上替代手机里的「Bimmer 控制器」，用于**查看车辆状态**和**远程控制车辆**。

- 常驻菜单栏，图标为 🚗，鼠标点开即看车况
- 后台每 60 秒自动刷新一次状态
- 登录采用短信验证码，App 内置交互窗口
- 本机数据全部保存在 `~/bimmer/` 目录，权限 600（仅本人可读写）

---

## 1. 安装

### 1.1 获取安装包

两种架构，二选一：

| 架构 | 文件 | 适用机器 |
|---|---|---|
| Intel（x86_64） | `Bimmer.dmg` | Intel Mac；Apple Silicon 需装 Rosetta 2 |
| Apple Silicon（arm64） | `Bimmer-arm64.dmg` | M1/M2/M3/M4 系列（原生） |

> Apple Silicon 机器上如需运行 x86_64 包，先装 Rosetta：
> `softwareupdate --install-rosetta`

### 1.2 安装步骤

1. 双击 `.dmg` 挂载
2. 把 `Bimmer.app` 拖进「应用程序」（dmg 里已放好 `/Applications` 快捷方式）
3. 首次启动若提示「无法验证开发者」：右键点击 App → 「打开」，或到
   「系统设置 → 隐私与安全性」点「仍要打开」

> App 为 ad-hoc 签名、未经 Apple 公证，因此首次启动需手动放行一次，之后正常。

### 1.3 首次启动前的配置

App 启动后会自动创建 `~/bimmer/` 目录，但**有两样东西不会随安装包分发**（凭据不打包）：

**① `~/bimmer/config.json`** —— 逆地理编码（位置显示）与充电统计所需：

```json
{
  "geo_provider": "baidu",
  "geo_key": "<你的百度地图 AK>",
  "battery_capacity_kwh": 9.7
}
```

- `geo_key`：百度地图开放平台申请的服务端 AK（用于把经纬度转成地址门牌号）
- `battery_capacity_kwh`：电池容量，用于估算每次充电的 kWh（不填默认 9.7）

**② 登录 token** —— 第一次启动时通过短信验证码登录自动生成（见下节），
无需手动准备；也可从已登录过的机器复制 `~/bimmer/tokens.json` 过来。

## 2. 登录（短信验证码）

**触发时机**：token 缺失或失效时，App 会自动弹出登录窗口；也可随时点菜单
「🔐 重新登录」手动触发。

**操作流程**（手机号 + 验证码在同一个窗口）：

1. 弹出「登录 BMW 互联驾驶」窗口，输入手机号（例如 `8613812345678`，带 86 前缀）
2. 点 **「发送验证码」** —— App 自动完成滑块验证并发送短信到手机
3. 手机收到短信后，把验证码填进「验证码」框
4. 点 **「登录」** —— 成功后 App 自动刷新车况

三个按钮的含义：

| 按钮 | 作用 |
|---|---|
| 登录 | 用当前手机号 + 验证码登录 |
| 发送验证码 | 滑块验证 + 发送短信（先做这步） |
| 取消 | 放弃登录 |

> 登录成功后 token 会保存到 `~/bimmer/tokens.json`（权限 600），下次启动无需重复登录，
> 直到 token 过期自动再次弹窗。

## 3. 菜单项说明

点开菜单栏 🚗 图标，从上到下依次为：

| 菜单项 | 内容 |
|---|---|
| （车名） | 车辆名称 |
| 🔋 电量 / 油量 | 剩余电量百分比、剩余油量 |
| 🛣 纯电 / 燃油 / 总 | 各续航里程 |
| 📏 总里程 | 总里程 + 本月累计（本地统计） |
| 🔌 充电状态 | 充电中/已充满/未充电 + 充电枪是否连接 |
| ⚡ 本月充电 | 本月充电量（kWh）+ 充电次数（官方接口） |
| 📊 充电趋势 | 子菜单：官方本月统计 + 本地充电会话记录 |
| 🔒 锁定状态 | 门锁状态，若有车窗/门盖开启会追加提示 |
| 📍 位置 | 逆地理编码后的地址（点击用 Apple 地图打开车辆位置） |
| 🚗 远程控制 | 子菜单，见下节 |
| 🔐 重新登录 | 手动触发短信登录 |
| 🔄 刷新 | 立即拉取一次状态 |
| 退出 | 退出 App |

菜单栏标题直接显示 **总续航里程**，出错时显示 ⚠️。

## 4. 远程控制 ⚠️

「远程控制」子菜单包含 9 个指令，**都会真实作用于车辆**，请确认意图后再点：

| 指令 | 说明 |
|---|---|
| 🔒 锁车 | 远程上锁 |
| 🔓 解锁 | 远程解锁（注意安全） |
| ❄️ 开启空调 | 远程开启空调 |
| ♨️ 关闭空调 | 远程关闭空调 |
| 📣 喇叭 | 鸣喇叭（常用于找车） |
| 💡 灯光闪烁 | 闪灯 |
| 🔌 开始充电 | 远程开始充电 |
| ⏹ 停止充电 | 远程停止充电 |
| 📍 寻车 | 触发车辆定位/寻车 |

> **安全提示**：远程指令通过宝马官方接口下发，会真实影响车辆（尤其解锁、开空调会
> 消耗电瓶/电量）。请在明确需要时使用。

## 5. 数据文件说明

所有数据都在 `~/bimmer/` 下，均 `chmod 600`：

| 文件 | 内容 | 是否需要手动准备 |
|---|---|---|
| `config.json` | 百度地图 AK、电池容量 | ✅ 首次需手动填 |
| `tokens.json` | 登录 token（mobile/gcid/refresh_token/access_token） | 登录后自动生成 |
| `stats.json` | 每月里程统计（月初里程 + 最新里程） | 自动生成 |
| `charge_stats.json` | 本地充电会话记录（起止时间/SOC/kWh） | 自动生成 |

> 这些文件包含个人凭据，请勿外传、勿提交到代码仓库。

## 6. 已知问题与限制

1. **架构**：x86_64 包在 Apple Silicon 上需 Rosetta 2；arm64 包需在 M 系机器上重新构建。
2. **未公证**：ad-hoc 签名，首次启动需手动放行。
3. **「锁车 / 解锁 / 开启空调」的确认框目前有 bug**：点击「确认」后可能不会真正执行
   （底层 `rumps.alert` 返回值判断有误，为「误禁用」而非「误触发」，方向是安全的）。
   其余指令（关空调、喇叭、灯光、充电、寻车）不受影响。此问题待修复。

---

## 7. 卸载

1. 退出菜单栏 App
2. 把「应用程序」里的 `Bimmer.app` 拖进废纸篓
3. （可选）删除 `~/bimmer/` 目录以清除 token、统计等所有本机数据
